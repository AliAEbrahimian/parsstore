Selected project: ParsStore
--------------------------------------------------------------------------------

Repository: https://github.com/AliAEbrahimian/parsstore

A bilingual (English/German) Django brochure site for a supplier of weaving
machine spare parts. It includes a paginated and searchable product catalogue,
part detail pages, quote-request and customer-club forms, automated WebP
thumbnails, two-layer email notifications, strict Content-Security-Policy,
atomic per-IP rate limiting and a hardened, configurable admin panel.

My work on the project included:

  * Designing the four-model data layer (Inquiry, Product, ProductSpec,
    Customer) and the admin workflow.
  * Building a searchable, filterable, paginated catalogue with database
    indexes and safe GET-parameter validation.
  * Implementing a bilingual string/content layer with language switching via
    query parameter and cookie, and removing the earlier third language.
  * Hardening the application: strict CSP, honeypot fields, atomic throttling,
    opt-in proxy trust and production deployment checks.
  * Writing the automated test suite and the CI workflow for Python 3.11-3.13.
  * Renaming the project from parstextile to parsstore and preparing the GitHub
    documentation (README files, DOCUMENTATION.txt).
